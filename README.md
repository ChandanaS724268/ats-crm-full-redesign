# ATS + CRM Full Redesign

## Project Overview

The ATS + CRM Full Redesign is a UI/UX design project focused on improving recruitment management and customer relationship management experiences.

The project aims to redesign Frappe HR ATS and EspoCRM using a unified design language, reusable components and consistent user experience.

## Objectives

- Improve usability and navigation.
- Create consistent interfaces across ATS and CRM.
- Develop a reusable design system.
- Simplify recruitment and customer management workflows.
- Improve accessibility and visual hierarchy.

## Project Modules

### 1. Applicant Tracking System (ATS)

- Job Management
- Job Creation Workflow
- Candidate Management
- Candidate Pipeline
- Candidate Evaluation
- Interview Scheduling

### 2. Customer Relationship Management (CRM)

- CRM Dashboard
- Leads Management
- Contacts Management
- Accounts Management
- Opportunities Management
- Sales Pipeline
- Activity Timeline

The project uses a shared design system consisting of:

- Navy and Teal colour palette
- Inter typography
- Reusable UI components
- Consistent buttons and form elements
- Standardised navigation
- Cards, tables and status indicators
